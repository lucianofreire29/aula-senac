# Aulas SENAC — Desenvolvimento de Sistemas

Repositório de estudos do curso Técnico em Desenvolvimento de Sistemas, reunindo exercícios, avaliações, exemplos e projetos desenvolvidos durante as unidades curriculares.

## Conteúdo

- **UC02:** fundamentos de Python, estruturas de dados, funções, exercícios e avaliações.
- **UC03:** programação orientada a objetos e relacionamentos entre classes.
- **UC04:** interfaces gráficas com Tkinter, arquivos CSV/JSON e miniaplicações.
- **Projetos:** trabalhos práticos organizados em pastas independentes.

## Como executar

1. Instale o [Python 3](https://www.python.org/downloads/).
2. Clone o repositório:

```bash
git clone https://github.com/lucianofreire29/aula-senac.git
cd aula-senac
```

3. Execute o arquivo desejado:

```bash
python caminho/do/arquivo.py
```

Em sistemas nos quais o comando principal é `python3`, use:

```bash
python3 caminho/do/arquivo.py
```

Alguns programas utilizam arquivos JSON, imagens ou outros recursos relativos. Nesses casos, entre na pasta do projeto antes de executar o arquivo principal.
